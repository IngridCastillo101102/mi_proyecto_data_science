# Data Science Learning Journey

> 20-day intensive study plan: Python, Data Analysis, Git, and Technical English.

##  Objectives
- Master Python fundamentals for Data Science.
- Perform Data Cleaning and Exploratory Data Analysis (EDA) with Pandas.
- Document projects and learn version control using Git & GitHub.

## Tools & Technologies
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib
- **Tools:** VS Code, Git, GitHub, Jupyter Notebooks

##  Repository Structure
- `data/`: Datasets used for practice.
- `notebooks/`: Exploratory Data Analysis notebooks.
- `src/`: Reusable Python scripts.
- `glossary.md`: Technical vocabulary list in English.
